This repository contains an extensive Exploratory Data Analysis (EDA) and visualization project based on the Global Terrorism Database (GTD). The analysis investigates historical trends, geographic hotspots, target types, and weapon categories associated with global incidents over time.

---

## 📊 Project Overview
* **Objective:** Perform in-depth data exploration and statistical analysis to uncover macroscopic trends and behavioral patterns in global security incidents.
* **Key Steps:**
  * Data cleaning, missing value handling, and date-time extraction across decades of records.
  * Temporal trend analysis (annual/monthly attack frequencies and evolutions).
  * Geographical and regional hot-spot identification.
  * Target and weapon preference correlation analysis.
  * Interactive dashboard deployment via **Streamlit** to filter and visualize metrics dynamically.

---

## 🛠️ Tech Stack & Libraries
* **Python**
* **Pandas & NumPy** (Data Aggregation & Analysis)
* **Matplotlib & Seaborn** (Statistical Charts & Plots)
* **Folium / Plotly** (Geospatial & Interactive Visualizations)
* **Streamlit** (Interactive Dashboard)
